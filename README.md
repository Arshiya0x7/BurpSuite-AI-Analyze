# Burp Suite AI Security Analyzer

A powerful Burp Suite extension that leverages AI to analyze HTTP requests and responses for security vulnerabilities, providing instant penetration testing insights.

## Features

### Core Functionality
- **AI-Powered Analysis**: Send HTTP requests/responses to AI models for security analysis
- **Dual Language Support**: Full English and Persian (Farsi) support with RTL text handling
- **Customizable Prompts**: Edit and save your own AI prompts for both languages
- **Right-Click Integration**: Analyze requests directly from Proxy History, Repeater, Target, and Logger
- **Request/Response Analysis**: Analyze single requests or both request and response together
- **Token Usage Tracking**: Monitor API token consumption (input/output/total tokens)

### User Interface
- **Dark Theme**: Eye-friendly dark interface optimized for long penetration testing sessions
- **Color-Coded Buttons**: Intuitive button colors for different actions
  - Green: Primary actions (Send, Save)
  - Orange: Configuration (Edit Prompts)
  - Purple: Settings (API Configuration)
  - Gray: Secondary actions (Clear, Load)
- **Split Panel Layout**: Request input on top, AI analysis results below
- **Status Indicator**: Real-time feedback on analysis progress and results

### Configuration
- **API Settings Dialog**: Configure API endpoint, API key, model selection, and max tokens
- **Persistent Settings**: All settings survive Burp Suite restarts
- **Connection Testing**: Built-in API connection test button
- **Default Values**: Pre-configured with working defaults for quick setup

## Installation

1. Download the `ai_analyzer.py` file
2. Open Burp Suite
3. Go to **Extender** → **Extensions**
4. Click **Add**
5. Select **Python** as extension type
6. Load the `ai_analyzer.py` file
7. The "AI Analyzer" tab should appear in Burp Suite

## Requirements

- Burp Suite Professional or Community Edition
- Jython standalone JAR configured in Burp Extender
- Valid API key for your AI service provider

## Usage

### Basic Usage
1. Enter an HTTP request in the top text area (or load from proxy/right-click)
2. Click **Send to AI** button
3. Wait for the AI analysis to complete
4. Review the security findings in the bottom panel

### Quick Analysis Methods
- **Manual Entry**: Type or paste HTTP requests directly in the text area
- **Load from Proxy**: Click "Load from Proxy" to load the most recent proxy request
- **Right-Click Menu**: Right-click any request in Proxy History, Repeater, or Target → "Send to AI Analyzer"
- **Request + Response**: Use "Analyze request and response" from right-click menu for full context

### Prompt Customization
1. Click **Edit Prompts** button
2. Customize English and/or Persian prompts
3. Use `{REQUEST}` as placeholder for HTTP content
4. Click **Save & Close**

### API Configuration
1. Click **Settings** button
2. Configure your API endpoint, key, model, and token limits
3. Click **Test Connection** to verify settings
4. Click **Save & Close** to persist settings

### Language Toggle
- Check/uncheck **Persian (Farsi)** checkbox to switch between English and Persian modes
- Persian mode enables RTL text direction for proper Farsi display

## Default Configuration

| Setting | Default Value |
|---------|---------------|
| API URL | `https://api.openmodel.ai/v1/messages` |
| Model | `deepseek-v4-flash` |
| Max Tokens | `10000` |

## Supported AI Providers

The plugin is compatible with any API that follows the Anthropic Messages API format:
- Anthropic (Claude models)
- OpenModel.ai
- Any custom endpoint supporting Anthropic-compatible API

To use with OpenAI-compatible APIs, change the endpoint URL in Settings.

## Features in Detail

### Security Analysis
The AI analyzes requests for:
- SQL Injection vulnerabilities
- XSS (Cross-Site Scripting)
- Authentication/Authorization issues
- Information disclosure
- Insecure headers
- CSRF vulnerabilities
- Input validation problems
- And more based on your custom prompts

### Token Tracking
After each successful analysis, token usage is displayed:
- **Input Tokens**: Tokens consumed by your request
- **Output Tokens**: Tokens generated by the AI
- **Total Tokens**: Combined token usage

This information appears both in the status bar and at the bottom of the response.

### Error Handling
- Graceful handling of API errors (401, 429, 500, etc.)
- Network timeout management (30s connect, 120s read)
- Clear error messages in the response panel
- Debug logging available in Burp Extender output

## Troubleshooting

**Plugin not loading?**
- Ensure Jython is properly configured in Burp Suite
- Check Extender → Options → Python Environment

**API connection failing?**
- Verify your API key in Settings
- Use the "Test Connection" button
- Check network connectivity and proxy settings
- Ensure the API URL is correct and accessible

**Getting authentication errors?**
- Confirm API key is valid and not expired
- Check if the model name is correct for your provider
- Verify the API endpoint URL format

**Slow responses?**
- Adjust max_tokens to a lower value for faster responses
- Check your network latency to the API endpoint
- Consider using a faster model
